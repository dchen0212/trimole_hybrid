# Trimole-Hybrid

Task-wise selection and combination of molecular predictors for the 22-task TDC ADMET benchmark.

## Releases

The [2026.10.28 code-and-data release](https://github.com/dchen0212/trimole_hybrid/releases/tag/v2026.10.28) provides the current model index and supplementary-data package. Checkpoints will be attached after transfer and hash verification; they are not part of this initial release.

The [published 2026.10.24 research archive](https://doi.org/10.5281/zenodo.23602309) remains unchanged. It preserves the original research code, result-to-code mapping, dependency documentation and archival analysis records.
