# External dependencies and execution scope

1. **TDC ADMET:** obtain benchmark datasets from https://tdcommons.ai/benchmark/admet_group/ using the dataset/split names in Supplementary Table S1. Frozen source hashes, counts and task names are in the companion archive. A current download need not equal the historical frozen bytes.
2. **KPGT / ChemBERTa / Uni-Mol / MiniMol:** acquire upstream code and pretrained weights from the URLs and version/hash bindings in each protocol. The archived public KPGT components keep their existing license. New third-party model binaries are excluded. MiniMol and Chemprop version/settings are in S3 and S5 plus their archived protocols.
3. **Recovered prediction pool:** the combination-stage scripts require the recovered validation/test prediction matrices and row identities recorded by the S4 companion ledgers. Aggregate task scores cannot reconstruct those matrices. They are not included as a substitute for data/model assets.
4. **Uncertainty/subgroups:** `revision/statistics/INPUT_HASHES.json` and `ROW_SOURCE_HASHES.json` identify saved prediction inputs. Row-level labels, molecular data and model predictions remain external. The included CSVs preserve calculated results, not sufficient statistics to regenerate every interval.
5. **Paths/environment:** original source snapshots retain server paths under `/mnt/data/projects/` and project-local paths. Recreate the named directory layout or adapt those paths for your own storage before execution. Environment and protocol records sit beside the relevant scripts. The current release is not a portable one-command training distribution.
6. **Two target-only replacements:** source entry points and exact fitted-artifact hashes are in `revision/target_only_evidence/LINEAGE.json` and CYP3A4's retained selection freeze. Final model binaries remain external. The original exploration and retained results are distinguished; this archive does not reclassify reused test data as an independent test.

See the included protocol files for package versions, seed settings, acquisition URLs and expected file hashes. Do not execute training or test-scoring entry points merely to verify the archive.
