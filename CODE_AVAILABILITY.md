# Code and data availability

This release provides source code, final task configurations and published result records. Checkpoint weights are not attached to the release. The 155-entry manifest describes located artifacts, including partial component sets; eight tasks have no saved original estimator. The package is not a complete set of assets for end-to-end reproduction of all 22 reported systems.

- Source code and usage: https://github.com/dchen0212/trimole_hybrid
- Current submission supplement: https://github.com/dchen0212/trimole_hybrid/blob/main/supplementary/supplementary.pdf
- Current table files: https://github.com/dchen0212/trimole_hybrid/tree/main/supplementary_tables
- Current figure files: https://github.com/dchen0212/trimole_hybrid/tree/main/supplementary_figures
- Full data, model configurations and current supplement: https://github.com/dchen0212/trimole_hybrid/releases/tag/v2026.10.28
- Paper-to-code mapping: https://github.com/dchen0212/trimole_hybrid/blob/main/docs/RESULT_CODE_MAP.md
- Immutable earlier code and analysis archive: https://doi.org/10.5281/zenodo.23602309
